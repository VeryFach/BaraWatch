Cara run database

1. Melalui NPM (Node.js): Jalankan npm install -g supabase di terminal.

Menjalankan Supabase via Docker

2. Buka PowerShell dan arahkan ke root folder proyek Anda (D:\Raka\lomba\BaraWatch).

3. Pastikan Docker Desktop dalam keadaan terbuka dan berjalan.

4. Jalankan perintah supabase start.

5. Supabase CLI akan otomatis menarik (pull) seluruh image Docker yang dibutuhkan (PostgreSQL, Auth, REST, Storage, dll) dan menyalakannya secara lokal. Proses ini membutuhkan waktu beberapa menit pada percobaan pertama.
